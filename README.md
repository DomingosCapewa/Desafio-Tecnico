# Desafio Técnico

Repositório com exercícios práticos em C# para demonstrar lógica de programação e organização de código.

## Exercícios

### Controle de contatos

Aplicação de console para cadastro e manipulação de contatos.

### Simulador de caixa eletrônico

Aplicação de console para simular operações básicas de um caixa eletrônico.

## Requisitos

- .NET SDK compatível com os arquivos `.csproj` dos exercícios.

## Executando

Entre na pasta do exercício desejado e execute:

```bash
dotnet restore
dotnet run
```

Projetos disponíveis:

```text
ControleDeContatos/
SimuladorDeCaixaEletronico/
```
